# Hardware certification

Status: `NOT CERTIFIED` until physical evidence exists.

Required separately from software release:

- Raspberry Pi 3 baseline, then Pi 4/5 and future supported models;
- physical PipeWire/ALSA capture/playback;
- USB audio and hot-plug;
- reboot/recovery;
- physical latency and XRUN behavior;
- controller-specific behavior;
- temperature, power and 60-minute endurance;
- complete mixer/interface/network/receiver/IEM path.

Absence means `NOT TESTED` or `NOT CERTIFIED`, not automatic software-release failure.
