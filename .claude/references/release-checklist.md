# Release Checklist

- [ ] `VERSION`, workspace manifest, and tag agree
- [ ] Local fmt, clippy, tests, frontend typecheck/tests/build pass
- [ ] CI jobs actually executed and passed
- [ ] x86_64 and ARM64 archives validated
- [ ] SHA-256 checksums generated and verified
- [ ] Ed25519 signature and public-key fingerprint verified
- [ ] SBOM generated
- [ ] Clean staging directory used
- [ ] Release notes reviewed
- [ ] Raspberry Pi validation status explicitly stated
- [ ] User confirmed publication
