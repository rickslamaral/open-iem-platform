# General Repository Rules

- Read root `CLAUDE.md` before work.
- Keep user-facing documentation in pt-BR, English, and Spanish mirrors when guides change.
- Never commit credentials, private keys, tokens, `.env` files, or production data.
- Mark PipeWire, ALSA, Opus, WebRTC media, and Raspberry Pi behavior as `SIMULATED` until physically validated.
- Update `docs/TODO.md`, `docs/DEVELOPMENT-LOG.md`, `CHANGELOG.md`, and phase review when completing a phase.
- Use Conventional Commits.
